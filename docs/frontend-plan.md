# План фронтенда (после пункта 32)

Фундамент: пункт 32.5 (lane + плавная перерасстановка + лежачий не поражается пулей
+ лежачий шире) — см. point-32.5.md.

Общий шаблон анимации действия: (разворот в нужную сторону, если надо) -> (дойти до
края, если надо) -> (основная анимация действия) -> (упорядочивание ковбоев в вагоне)
-> (финальный взгляд: в исходную сторону или по правилам действия).

## Пункты

- 33 Синхронизация: события WS -> game store + очередь анимаций (последовательно).
- 34 Веер карт + перетаскивание в 3 слота (первое/второе/третье действие).
- 35 Оркестрация розыгрыша: карта раскрывается -> поезд плавно прокручивается к ковбою
      -> запуск анимации действия.
- 36 Действие «Переместиться» (walk).
- 37 Действие «Сменить уровень» (climb): к хвосту -> дойти до края -> к локомотиву ->
      climbing -> крайний со стороны хвоста на крыше -> исходный взгляд.
- 38 Действие «Развернуться» (rotate).
- 39 Действие «Выстрел» (shoot + полёт пули + отброс цели).
- 40 Действие «Лошадь» (horse).
- 41 Действие «Выстрел от бедра» (hip fire: встать+выстрелить / лечь).
- 42 Состояние «стоит» (staying + взгляд left/right).
- 43 Состояние «навзничь» + «вставание» (laying + getup).
- 44 Отброс (fall forward/back + приземление в навзничь).
- 45 Отцепление вагона и выбывание.
- 46 Фоновое движение поезда (параллакс).
- 47 Таймеры фаз.
- 48 Спрайты (цвета) + звук.
- 49 Экраны результатов ($, победитель, выбывшие).

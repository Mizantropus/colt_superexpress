# Пункт 32.5 — позиционирование ковбоев в вагоне

Доп. требования к позиционированию бандитов (между п.32 и п.33). Накоплено в ходе Q&A.

## Требования

1. **`lane` вместо `edge`**: целочисленный порядок внутри «вагон + уровень»
   (0 = ближе к хвосту / левее, больше = ближе к локомотиву / правее).
   - вход со стороны хвоста → левее всех (lane = 0, остальные сдвигаются +1);
   - вход со стороны локомотива → правее всех (максимальный lane).

2. **Плавная корректировка**: при появлении/уходе ковбоя все ковбои вагона
   плавно (CSS transition) перераспределяются, чтобы стоять ровно.

3. **Лежачий не поражается пулей**: `_find_shoot_target` должен пропускать
   бандитов с `posture == PRONE` (пуля летит на высоте стоящего — над лежачим).

4. **Лежачий шире**: спрайт `laying` (63px) шире `staying` (48px) — учитывать
   при равномерной раскладке по горизонтали.

5. **$ за отцепленный вагон**: лежачий считается «ближайшим» наравне со стоящим;
   «ближе всех» определяется позицией (левее = ближе к хвосту), а не позой.
   (Текущий `_closest_to_detached` уже не пропускает prone — ок.)

## Затрагивает

- backend: `Position.edge` → `lane`; действия move/shoot/отброс; `_find_shoot_target`
  (skip prone); `_closest_to_detached` (порядок по lane); сериализация; тесты.
- frontend: отрисовка бандитов (lane + равномерная раскладка + transition + ширина laying).
